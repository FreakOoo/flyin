2. What does std::fs::read_to_string mean?

Let's break that name down:
rust

std::fs::read_to_string("config.txt")

    std — Rust's standard library.

    fs — the filesystem module inside that library.

    read_to_string — a function that reads a file and returns its contents as text.

    "config.txt" — the argument passed to that function.

The :: operator lets you navigate through those namespaces.

You could shorten it with an import:
rust

use std::fs;

fs::read_to_string("config.txt")

Both versions call the same function. The first spells out the full path; the second brings fs into scope.
3. What is .expect()?

For now, just think of it as an error check.
rust

let contents = fs::read_to_string("config.txt")
    .expect("Failed to read config.txt");

Reading a file can fail. Maybe the file doesn't exist, or you don't have permission to read it.

Rust represents the result as either success or failure. .expect() says:

    If reading succeeds, give me the contents.

    If reading fails, stop the program and display an error message.

It's convenient while you're learning. Later, we'll look at proper error handling.
4. Let's actually start the parser

Create parser.rs with just this:
rust

use std::fs;

pub fn read_config() {
    let contents = fs::read_to_string("config.txt")
        .expect("Failed to read config.txt");

    for line in contents.lines() {
        println!("{}", line);
    }
}

Assume config.txt contains:
text

drone_count=5
zone_count=10
capacity=20

Run your program:
bash

rustc main.rs
./main

You should see those three lines printed.
What does the loop do?
rust

for line in contents.lines() {
    println!("{}", line);
}

There are two separate things here:

    contents.lines() is a standard-library method that produces the individual lines of the text.

    line is a variable name you chose. It holds the current line on each iteration.

Rust doesn't infer the word lines from the variable line. lines() is an existing method, just as strlen() is an existing function in C.

And the braces { ... } define the body of the loop: everything inside runs once for each line.

6. What we'll do next

We'll build this parser in small steps:

    Read and print each line. That's what the code above does.

    Split a line like capacity=20 into a key and a value.

    Store the key-value pairs in a HashMap.

    Retrieve values like capacity and convert them into integers.

    Decide how to pass the finished configuration into your main program.

A HashMap is indeed a pre-existing data structure in Rust's standard library, and Some is a variant of the built-in Option enum. But neither is needed for step one, so we can leave them alone for now.
